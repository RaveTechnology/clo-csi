## Проверка 19.11.2026

Свободный native диск10→12GB снова перешёл в ERROR напрямую через API без CSI.
Дополнительный тест подключённого PVC выявил дефект инициализации записи операции:
Kubernetes удалял apiVolumeIDs:null из spec, нарушая сохранённый digest. В rc.2
поле допускает null. Для прежней записи допускается только восстановление
представления, доказанного исходным v1 hash, без изменения сохранённых spec/UID
или сброса Sent. Перед обновлением controller требуется отдельно применить CRD.

Регрессия воспроизведена и проверена на реальном Kubernetes API: nil, пустой и
непустой список, status CAS и отказ восстановления потерянного использованного
status. Полный production gate остаётся закрытым; дополнительный эксперимент
с подключёнными PVC описывается отдельно от прежнего полного csi-sanity.
